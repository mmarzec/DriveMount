# ADR-0003: Licence: GPLv3 open source with WinFsp

| | |
|---|---|
| Status | **Accepted** |
| Date | 2026-11-03 |
| Decided by | Project owner |
| Resolves | OD-1 (SPECIFICATION.md §12.2) |

## Context

DriveMount creates drives by loading **WinFsp** into its own process, through the **`winfsp` Rust crate**. NEO SSH-Win Manager is different: it only starts SSHFS-Win as a separate program. Because of this, the licences of WinFsp and of the crate apply to DriveMount whenever it is distributed.

| Component | Licence | Effect |
|---|---|---|
| WinFsp | GPLv3 with a FLOSS exception (see `License.txt` in the WinFsp install folder) | An open-source app under any OSI/FSF-approved licence may (1) link the WinFsp DLL and (2) redistribute the **unmodified** WinFsp installer, provided it (a) shows "WinFsp - Windows File System Proxy, Copyright (C) Bill Zissimopoulos" and a link to the WinFsp repository in its UI and user-facing docs, and (b) is not linked or distributed with proprietary software. Closed-source apps need a commercial licence. |
| `winfsp` / `winfsp-sys` crates | GPL-3.0, no exception | Linking them makes the distributed app GPLv3 |
| Slint | GPLv3, or royalty-free (desktop, with attribution), or commercial | Usable under its GPLv3 option |
| Other dependencies (russh, tokio, windows-rs, serde, tracing…) | MIT / Apache-2.0 and similar | Compatible with GPLv3 |

## Decision

1. DriveMount's own source code is licensed **GPL-3.0-or-later**. Distributed binaries include GPL-3.0-only dependencies, so they are conveyed under GPLv3.
2. Use **WinFsp** with the **`winfsp` crate** as planned. Slint is used under its GPLv3 option.
3. We **also meet the conditions of WinFsp's FLOSS exception**: the attribution notice and no proprietary components. It costs nothing, and it gives a clear right to bundle the unmodified WinFsp installer (OD-5).

## Obligations (become NFR-LIC-01 to NFR-LIC-05 in the specification)

| # | Obligation | How |
|---|---|---|
| 1 | Licence declared | `LICENSE` (full GPLv3 text) in the repository root; `license = "GPL-3.0-or-later"` in every crate's `Cargo.toml`; `// SPDX-License-Identifier: GPL-3.0-or-later` at the top of each source file |
| 2 | WinFsp attribution | About section and user guide show "WinFsp - Windows File System Proxy, Copyright (C) Bill Zissimopoulos" with a link to https://github.com/winfsp/winfsp |
| 3 | Our licence and source visible | About section shows "Licensed under the GNU GPL v3", a link to the source repository, and opens the bundled third-party licence file |
| 4 | Third-party notices | `THIRD-PARTY-LICENSES.html` generated by `cargo-about`; shipped in the MSI and zip |
| 5 | Source for every release | Every release tag is public in the source repository; release notes link to the matching source |
| 6 | No proprietary components | Nothing proprietary is linked or bundled; enforced by the `cargo deny` allow-list below |

### `cargo deny` licence allow-list

All of these are compatible with distributing the combined work under GPLv3:

```toml
[licenses]
allow = [
  "GPL-3.0", "GPL-3.0-only", "GPL-3.0-or-later",
  "LGPL-3.0", "LGPL-3.0-only", "LGPL-3.0-or-later",
  "MIT", "MIT-0", "Apache-2.0", "Apache-2.0 WITH LLVM-exception",
  "BSD-2-Clause", "BSD-3-Clause", "ISC", "Zlib", "0BSD", "BSL-1.0",
  "CC0-1.0", "Unicode-3.0", "Unicode-DFS-2016", "MPL-2.0",
]
# Slint is "GPL-3.0-only OR <Slint royalty-free> OR <Slint commercial>": accepted through its GPL-3.0-only alternative.
```

**Not allowed:**
- `GPL-2.0-only`, which is **incompatible** with GPLv3;
- any proprietary or unknown licence;
- `SSPL` and other non-OSI licences.

Exceptions need a new ADR.

## Consequences

**Positive**
- No extra engineering. We use the fastest drive framework and its tested safe Rust bindings, as specified.
- The installer may bundle the unmodified WinFsp MSI.
- Binaries may still be sold. The GPL governs freedoms, not price.

**Negative / accepted**
- Anyone who receives the app can get, modify and redistribute the source. Forks must also be GPLv3.
- Companies cannot embed DriveMount code in closed-source products.
- Going closed-source later would mean replacing `drivemount-winfsp` (Dokany, or a commercial WinFsp licence with our own bindings) and relicensing any third-party contributions.

**Note:** these obligations apply only when the program is **distributed**. Personal or in-house use triggers none of them.

## Alternatives considered

| Option | Why not chosen |
|---|---|
| Permissive open source (MIT/Apache) under WinFsp's FLOSS exception, with our own bindings | Extra work package; we lose the tested safe wrapper; no need for a permissive licence |
| Closed source with Dokany | Likely slower; a different driver to install; closed source not wanted |
| Closed source with a commercial WinFsp licence | Cost and negotiation, plus our own bindings; closed source not wanted |

*This record documents an engineering decision. It is not legal advice.*
