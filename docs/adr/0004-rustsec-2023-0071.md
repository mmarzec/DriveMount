# ADR-0004: Accept RUSTSEC-2023-0071 in the `rsa` crate

| | |
|---|---|
| Status | **Accepted** |
| Date | 2026-11-04 |
| Decided by | Project owner, in plan task M1-08a |
| Applies to | `deny.toml`, `.cargo/audit.toml` |

## Context

`russh`'s `rsa` feature brings in `rsa` 0.10.0-rc.18, which has RUSTSEC-2023-0071, the "Marvin" attack: private-key operations are not constant-time, so someone timing many of them may recover the key. It is rated medium, and the advisory lists no fixed version. `cargo deny` and `cargo audit` fail on it, and CI runs both.

FR-SSH-02 requires RSA login keys, and servers whose only host key is RSA must stay reachable (FR-SSH-15). Both need this feature.

## Options

| | Ignore this advisory, with a record | Drop the `rsa` feature |
|---|---|---|
| RSA login keys | Work | Stop working; FR-SSH-02 has to change |
| Servers with only an RSA host key | Work | Unreachable |
| CI | Fails on any other advisory, as before | Clean, with no ignore |

## Why the exposure is small

- FS Manager is only an SSH client, so it never decrypts with RSA and offers no service that performs private-key operations on request.
- Verifying an RSA host key uses the public key, which the attack does not concern.
- An RSA private key is used only to sign the user's own logins (from M1-08b), a few times per mount, against a server the user chose after its host key was checked. The attack needs a large number of precisely timed operations, and an attacker cannot make the client perform them at will.
- With the *SSH agent* method, the agent signs, not this code.

The remaining exposure is a user with an RSA key file whose logins are timed by someone able to observe them closely. Ed25519 and ECDSA keys are not affected.

## Decision

Ignore RUSTSEC-2023-0071, and only that advisory, in `deny.toml` and `.cargo/audit.toml`. Keep the `rsa` feature.

## Consequences

- Any other advisory in `rsa` or elsewhere still fails CI.
- **Revisit** at each `russh` or `rsa` upgrade, and remove both ignores as soon as a fixed `rsa` is available. `cargo deny` warns if the ignore stops matching anything.
- If this code ever acts as an SSH server, or signs with RSA on request from others, this decision no longer holds.
